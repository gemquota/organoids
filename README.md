# Organoids

A minimal generative physics prototype exploring emergence from particles through larger organised structures.

- [Live prototype source](./accretion.html)
- [Unified emergence architecture](./docs/EMERGENCE.md)
- [Shared runtime](./emergence.js)

## Development

```sh
npm test
```

GolfCore supplies generic declarative execution; the shared substrate adds entity, relation, physics, field, energy and reaction systems. The browser prototype is standalone and mirrors the tested runtime.
